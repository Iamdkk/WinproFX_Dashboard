# WINPRO FX Dashboard

This Power BI project visualizes forex and crypto trading performance using a demo dataset. It provides insights into profit/loss by currency pair, trade count, earnings by trade type, and performance across different global market sessions.

## 🔍 Features

- **Profit/Loss Analysis**: Total profit and loss visualized per trading pair.
- **Trade Distribution**: Trade counts broken down by trading pair and type (Buy/Sell).
- **Market Session Insights**: Profitability segmented by global market sessions (London, New York, Sydney, Tokyo).
- **Portfolio Overview**: Summary metrics showing total portfolio value, cumulative profit, and loss.

## 📊 Tools Used

- Microsoft Power BI
- Excel (Demo Dataset)

## 📁 Dataset

The dataset (`WINPRO_FX_Dashboard_Demo_Dataset_v3.xlsx`) includes simulated trades in forex and crypto pairs like USD/JPY, BTC/USD, ETH/USD, etc., with attributes such as trade type, market session, and P/L data.

## 🧠 Purpose

This dashboard serves as a demonstration of performance tracking for active forex/crypto traders and is useful for analyzing trade efficiency and strategy effectiveness.
